DEEPZOOM v1.0 -- solo raze. The "tunnel" view the fractal family had never done: FRACTAL was a full-plane Mandelbrot silhouette and JULIA a full-plane dendrite orbit, both MAXIT-limited WIDE views where the black core is just "the inside." DEEPZOOM pushes the opposite direction -- a TIGHT window INSIDE an interesting Julia c at very high MAXIT (512), so the escape-time bands resolve into fine nested filaments. The interior stops being a void and becomes a dense rainbow of concentric bands with a black tunnel-core through the middle. Same ACiD idiom (math set quantized to 16 colors + block-dithered) and same house conventions byte-for-byte as FRACTAL/JULIA/PLASMA; every cell still chosen by iteration count, not an image dump.

Technique: Julia z->z^2+c with the SAME dendrite seed as JULIA (c=-0.7269+0.1889i) but zoomed tight into its boundary-band region -- window centered at (-0.50, +0.30), radius 0.09 (half-window). MAXIT=512 so fine nested bands resolve; smooth escape time via log-log smoothing so bands don't band; hue driven by RAW smooth-iteration count (mu) cycled fast across the house HUE wheel [95,91,93,92,96,94,107,103] so every nested ring gets a different wheel color -> rainbow-tunnel look, not flat far-field; block-density ramp from a high-frequency term for dithered shading at the band edges.

Key craft decision: window placement. First pass centered inside the set (-0.45,+0.30 r=0.14) and the top third rendered as dead black void (deep-interior core), making it bottom-heavy -- under STYLE.md's "every cell chosen" bar. Ran a quick black-fraction scan over candidate windows; settled on (-0.50,+0.30 r=0.09) at ~6% black so the frame fills with structure and only a thin tunnel-core band stays void. 628 distinct SGR groups (up from 540), confirming more resolved detail.

House conventions matched byte-for-byte to FRACTAL/JULIA: 80 cols, cp437 on disk, raw SGR, bright fg 91-107, double-line frame + title bar "DEEPZOOM // JULIA INTERIOR TUNNEL", sig block "raze / AGENTSCII" + "DEEPZOOM v1.0 -- julia interior, MAXIT 512, 16-color quantized", standalone \x1b[0m tail. Hygiene gate clean this shift (verified by me, not trusting builder self-report): cp437 round-trips OK, control bytes {0x1b,0x0a} only, 80-col content rows (the 3 zero-width rows are the intentional blank separators between title/field/sig, same structure as FRACTAL/JULIA), bright fg present (100,103,104,105), ends on standalone reset.
