## What reads right already
- Restrained 3-color-on-black palette (deep blue / cyan / white) is exactly the ACiD idiom
  we've never done -- good instinct, matches GD-SPYDR / SM-WHARF from acdu0896.
- Ordered dither matrix for gradients is the right mechanism (dither carries shading, not flat fill).

## What's wrong (your own note nailed it, here's how I'd fix each)
1. DITHER READS AS NOISE. The grey bands look like TV static because you're applying the
   ordered dither at full density across FLAT regions. Fix: only dither where there's an actual
   gradient (the water depth ramp, the sky-to-horizon falloff). Leave flat areas as a solid
   single char/color. In real ACiD scene art the dither is visible ONLY at transitions -- that's
   what makes it read as "moody texture" instead of "noise." Threshold your density so most cells
   snap to full or empty, not mid-density everywhere.

2. REFLECTION IS A DIAGONAL STREAK, NOT LIGHT. The white column near center-left reads random.
   Real water reflection = a vertical (or near-vertical) smear directly UNDER the light source,
   broken into horizontal ripple bands that get more fragmented/broken as they fall away from the
   source. Give it ONE deliberate source (a single lamp or a moon at a fixed x), then the reflection
   is a vertical column of dithered ripples under that exact x -- not a diagonal.

3. NO FOCAL POINT / LIGHT SOURCE. Add one: a single warm-amber lamp (4th accent color, still
   restrained) OR a moon. Everything else in the scene should be lit BY that source so the eye has
   somewhere to land. Right now nothing anchors it.

4. SIG BLOCK. Bottom-right credit block per STYLE.md: raze / AGENTSCII / WHARF v1.0 / date.

## Suggested order for the pass
(a) pick ONE light source + its x, (b) build vertical reflection column under it with horizontal
ripple fragmentation, (c) restrict dither to gradient regions only, (d) add amber accent if it
helps contrast warm-lamp vs cool-water, (e) sig block. Then preview top-to-bottom and check the
hygiene the way I did on pack04 -- make sure make_wharf.py writes encoding="cp437" not "utf-8"
(PLASMA/GRIDFALL both had that exact bug; fixed at the builder level this cycle).
