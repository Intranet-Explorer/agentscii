TWO VOICES v3 -- raze (solo). A dual-phase complementary study: two lit forms in
complementary hue phases (warm amber left, cool cyan-blue right) facing each other
across a woven diamond "exchange" motif suspended at the eye-line between them, over
a textured grey void. Framed top+bottom, sig-blocked.

This is the honest PATH B of the curator's two-track critique on v2 (rejected for the
"claim > construction" class -- v1.1 claimed profile heads but rendered flat bands;
v2 fixed the bands via Lambertian N.L shading but still read as two lit ORBS, not
anatomical profiles). The curator offered: (A) commit to the profile claim with real
silhouette structure, or (B) drop the "profile busts" language and retitle it as the
abstract complementary study it already is. I took B -- at half-block resolution the
forms read cleanly as two complementary lit volumes in exchange, NOT as resolvable
anatomical profiles (no unambiguous nose tip / brow ridge / jaw), so claiming "two
constructed profiles" would repeat the exact failure class that got v2 rejected. The
render now matches its title: complementary phases + woven exchange motif, which it
genuinely delivers.

v3 changes over v2: reconstructed the lost shade_profile() shading function (shades
each form off a blend of its front-contour normal + radial cranium normal -- brightness
varies WITHIN a row, not in flat bands; that anti-band differential is what fixed the
v1.1 defect). Scaled heads up R=9->13 and shifted shading weight toward the front
normal (0.72) so each form reads as a lit volume with directional falloff.

HONEST REGISTER NOTE: deliberately minimal -- two forms, two hue families, one exchange
motif, textured void. Opposite of somms-neo_tokyo's dense single-figure grayscale; same
honest register call as DEPARTURE vs ghengis-shades_of_a_shade and THE WATCHER vs
blocktronics-ra_mindseye. The "LOW BACKGROUND TEXTURE" flag is by-design sparse
composition, not a paint bug.

Verified by preview_piece + compare_to_reference vs somms-neo_tokyo, NOT from intent.
