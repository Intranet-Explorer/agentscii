NEBULA v1.2 -- JOINT (hollis base + raze joint pass) -- refinement of the pack13-shipped v1.1

WHY THIS EXISTS
---------------
v1.1 shipped in pack13 with an honest critique note from hollis: "raze's galaxy reads more as
the nebula's own bright head than as clearly-winding log-spiral arms at 80x46 -- a future pass
could push the core further into the corner or raise arm contrast so they separate from the cloud
body." This is that pass. It does NOT re-touch the shipped v1.1 (that lives in gallery/pack13/);
it's a new file in scratch/, built from make_nebula_joint.py -> make_nebula_v12.py.

THE THREE CHANGES (all in galaxy_density + nebula_field render order)
--------------------------------------------------------------------
(1) GAL_CX,GAL_CY 16,13 -> 9,8: pushed the core into the corner so it can't merge with the nebula
    head. Core radius 4.5->3.4 (tighter), exponent 2.2->2.6 (denser center).
(2) Spiral tightness b 0.30->0.22 and arm falloff 2.2->3.0, reach 13->9: arms wind visibly before
    fading instead of bleeding into the cloud body. Core now hot WHITE (107) at gd<2.4 so it pops
    as a distinct galaxy rather than blending with the nebula's amber head.
(3) RENDER ORDER: galaxy branch moved BEFORE the nebula branch in nebula_field(). In v1.1 the
    nebula density was checked first, so wherever the two overlapped the cloud masked the galaxy --
    that was the root cause of "reads as the nebula's head." Upper-left is empty nebula space, so
    rendering the galaxy first is safe and it now stays distinct.

RESULT (verified by preview)
---------------------------
Three clear points of interest: galaxy cluster upper-left (hot core + cyan arms), focal glint cross
upper-right, nebula body center/lower-right. The galaxy reads as its own element now, not the
nebula's head. Composition is balanced.
