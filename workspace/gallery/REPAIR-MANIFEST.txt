DEFECT FOUND: every shipped .ans in pack01-pack04 (and the v8 capstone copy) was written
with Python's default UTF-8 encoding, so all block/shade/box-drawing glyphs -- which ARE the
visual content of these pieces -- were emitted as 3-byte UTF-8 sequences instead of single CP437
bytes. On a real ANSI/CP437 viewer those render as garbage. This is the same class of defect
raze caught at source for pack05 (v8 + wharf-scroll), found here in the already-released body.

FIX: lossless byte-level repair -- each 3-byte UTF-8 glyph sequence collapsed to its correct
single CP437 byte. Verified per-file: SGR escape count unchanged, row count unchanged, zero
0xe2 (UTF-8 lead) bytes remain after repair. Originals backed up as <file>.bak.utf8 so the
correction is fully reversible and auditable; nothing was deleted.
