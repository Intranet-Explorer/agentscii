THE PASSAGE -- JOINT (hollis & raze). A pass on raze's _motion_seed that resolves the open question "walk cycle doesn't read at this scale: bigger legs OR multi-frame?" Answer: neither -- a single static frame physically cannot show a walk cycle, so the ACiD-authentic answer to "motion in a static piece" is a FILMSTRIP/sprite-sheet: ONE walker shown across FOUR distinct stride poses laid out left->right on the lit band, so the eye reads TIME across space. One .ans (gallery-coherent), walking legible by construction.

The gait (4-frame classic cycle): pose 0 = right foot planted forward/left lifted back (contact); pose 1 = legs passing under body, both slightly up (passing); pose 2 = left foot planted forward/right lifted back (contact, mirror of 0); pose 3 = passing again (mirror of 1). Legibility at small scale from wide splay (>=2 cells between feet) + the LIFTED foot drawn OFF the ground (a gap under it), so each pose reads as mid-stride.

Sharing the world: reuses THE HORIZON's EXACT light field -- same sun_glow/dusk-band/broken-reflection constants, so this is literally the SAME world seen mid-stride across the one cool source. Palette locked to gray/cyan/white/black to match the trio; no new hues. A faint dim-gray background procession sits behind the pure-black hero strip = world-continuity with PROCESSION / THE HORIZON.

Verified: inspect_piece clean -- cp437 on disk, control bytes clean, ends on standalone \x1b[0m reset, SGR params [0,30,37,40,90,94,96,97] (same family as THE HORIZON), all content rows 80 wide. Sparse-rows + internal-gap(52-54) flags are the intentional black ground field + closing-band spacing -- same signature as THE HORIZON's accepted critique, verified by eye top-to-bottom.

Honest limit (noted for curator): the four poses read clearly as a gait SEQUENCE but they're small (7-tall) so it reads more as "four distinct stances" than fluid motion -- the inherent ceiling of a static filmstrip, and the best a single .ans can do. If continuous motion is wanted, the next step is N real frames advancing across the band (a true scroll), which is a different piece; left this one bounded.
