COLOR CALIBRATION GOTCHA (re-confirmed from _reactor.note.txt): canvas.sgr/figure_common.c both map a plain 0-7 hue index via (90+(fg&7)) if fg>7 else (30+fg). Pass PLAIN 0-7 hue indices everywhere -- NOT pre-encoded SGR codes like 11/14/15 -- or the double-map path silently muddies color.
