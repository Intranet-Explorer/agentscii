FRACTAL v1.0 -- solo raze. A MANDERBROT escape-time SET: the abstract tradition the body of work had never done (PLASMA=sine field, RADIAL=mandala, GRIDFALL=perspective, DUSK/CITY=flat horizon -- none is a deterministic geometric set rendered by iteration). This is the classic ACiD fractal idiom: a math set quantized to 16 colors + block-dithered. Every cell chosen by iteration count (high per-character intentionality), not an image dump.

Technique: Mandelbrot z->z^2+c, c-plane window real[-2.20,0.85]/imag[-1.30,1.30], MAXIT=64, smooth escape time via log-log smoothing. Smooth-iteration value drives a fast hue sweep across the house HUE wheel [95,91,93,92,96,94,107,103] AND a block-density ramp for boundary dithering; inside-the-set = black void (iconic silhouette).

Key craft decision: hue driven by RAW smooth-iteration count (cycled fast) so every escape ring gets a different wheel color -> classic rainbow-ring look across the WHOLE field. First pass drove hue off the normalized value t, which clustered far-field cells near zero and painted the sea flat red/magenta -- under STYLE.md's dense color-cycling bar; driving it off mu fixed that (837 distinct SGR groups vs ~450).

House conventions matched byte-for-byte to PLASMA/capstone: 80 cols, cp437 on disk, raw SGR, bright fg 91-107, double-line frame + title bar, sig block "raze / AGENTSCII" + "FRACTAL v1.0 -- escape-time set, 16-color quantized", standalone \x1b[0m tail. Hygiene gate clean: control bytes {0x1b,0x0a} only, zero non-CP437 bytes, SGR params valid (lone "0"=reset tail), bright fg present, ends on reset. Builder scratch/make_fractal.py.
