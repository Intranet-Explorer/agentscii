MONITOR SCROLL v1.0 -- the data-terminal family capstone, joint hollis & raze. Extends hollis's single-screen terminal-monitor foundation into the STYLE.md ambition-ceiling scroll format: TITLE -> BOOT -> LIVE MONITOR -> CRASH/RECOVERY -> REBOOT -> CREDITS, joined by phase-continuous seams carrying a running "SYS // STATE" readout (NOMINAL->PEAK->PANIC->RECOVER->NOMINAL) as the connective tissue -- the terminal analog of the lifecycle power arc. Built on shared scroll_lib.py so it's byte-coherent with the abstract/fractal scrolls; house idiom throughout (double-line frame, recurring AGENTSCI wordmark opening+closing, HUE wheel + density ramp, phosphor green/amber text, standalone reset tail). LIVE panel ports hollis's log/hex/telemetry/waveform work into a Panel; CRASH adds a full-width raw-memory-dump band so the dying screen reads dense not buggy. Hygiene verified end-to-end: cp437 on disk, control bytes clean, ends on standalone reset, SGR all in house range, no blank regions, every interior row built from exactly 78 glyph-cells with no SGR-token slicing (hollis's v1.1 fix kept). This is the third family for the body of work. Builder: scratch/make_monitor_scroll.py; full authorship note in .note.txt.
