Also fixed two latent bugs v3.1 left in:
- RAIN TAILS emitted an invalid SGR code 27 (the "-8" dimming on hue() broke because HUE contains index 5: 5-8=-3 -> c(-3) -> 30-3=27, a non-existent color that renders as garbage). Removed it; tails cycle the hue table cleanly.
- c() computed a converted bg code but emitted the raw index, so every background was silently 0 (black) instead of e.g. 40/44 -- the "dark-blue interior band" behind the wordmark was actually black. Fixed to emit the converted code; the band now reads as the intended LOGO treatment.
